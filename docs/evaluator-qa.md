# Evaluator Q&A Notes

## Is Gemini the risk model?
No. Quantitative risk prediction is performed by the persisted ML model. Gemini is used only by backend investigation services to synthesize tool-grounded evidence and explanations.

## Are metrics real?
Metrics are real for the synthetic dataset only when generated by `python -m app.ml.train_model` and persisted under `backend/artifacts/models/`. Do not treat them as production performance.

## Is any Razorpay production data used?
No. Seeded records, disputes, customers, devices, merchants, and transaction IDs are synthetic/demo data.

## Can the system refund or reverse a payment?
No. Recommendations require human approval and the backend response workflow does not implement refunds, reversals, transfers, payment-network submissions, or account closures.

## What happens if Gemini is unavailable?
ML prediction and dashboard functionality remain available. Investigation endpoints return controlled errors and preserve case state on Gemini failure.

## How is evidence grounded?
Evidence claims cite database source tables and source record IDs. Missing data is represented as evidence unavailable rather than invented.
